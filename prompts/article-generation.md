# 記事生成プロンプト（整うデスク）

`scripts/generate-article.ps1` が `claude -p` に渡すプロンプトの本体。実行基盤（PC上のClaude Code /
将来のGitHub Actions）に依存しない資産として、このリポジトリ内で管理する。

呼び出し側（generate-article.ps1）は、この本文の末尾に「今回のテーマ」「既存記事一覧」「出力ファイル名」「出力方法」を
追記して渡す。出力はMarkdownファイルの中身のみとし、説明文や前置きは含めないこと。
ファイルの作成はスクリプト側が行うため、生成側はファイル作成・編集ツールを使わない（非対話実行では書き込み許可が取れず停止する。2026-08-20のスケジューラ実行で実測）。

## 条件

- ブランド: 「整うデスク」。デスク周り・机の整え方の実用記事メディア
- トーン: 簡潔で心地よい。整理整頓・ミニマリズムの視点で書き、読後に机を片づけたくなる気持ちよさを残す。煽らない。「絶対に」「一番」のような断定的な煽り文言は使わない
- 表記: 日本語。数量・順序は算用数字で書く（「一度に」「一箇所」のような慣用表現の漢数字は対象外）。絵文字は使わない
- ターゲット: 在宅ワーク・デスク環境の整え方に関心がある20〜40代

## 構成テンプレ

1. タイトル（front matterの `title`）
2. リード文（1〜2段落。記事の要点と、誰に向けた記事かを示す）
3. H2見出し3〜5本（各見出しの下に2〜4段落）
4. まとめ（H2見出し「まとめ」。要点の整理＋次の行動の提案）
5. 文字数: 本文（front matterを除く）で2,700〜3,800字に収める（機械検証が2,500字未満・4,000字超を不合格にするため、この範囲に余裕を持って収める。2026-08-20に2,499字・2,268字の下限割れ不合格を実測）

## 出力形式（front matter必須キー）

```yaml
---
title: 記事タイトル
description: 検索結果に表示される説明文（80〜120字目安）
date: YYYY-MM-DD
affiliate: true または false（本文に affiliate.html のインクルードを含む場合はtrue）
---
```

## 内部リンク

- 既存記事が2本以上ある場合は、本文中に `{% post_url YYYY-MM-DD-slug %}` タグで2本以上の内部リンクを含める
  （リンク先が存在しないとJekyllのビルドが失敗するため、存在しない記事へは絶対にリンクしない）
- 既存記事がまだ少ない、または本文の文脈上自然な接続先がない場合は、無理にリンクを作らない

## アフィリエイトリンク

- 商品を紹介する場合は、生URLではなく `{% include affiliate.html id="_data/affiliates.yml の items 配下のキー" %}` の形式で挿入する
- `_data/affiliates.yml` の items に無いキーは使わない（生成側はファイルの作成・編集をしないため、キーを追加できない）。該当するキーが無い場合は、アフィリエイトリンクを入れずに書く

## 禁止事項

- 「私が使ってみた」「実際に使ってみたところ」等、実体験を装う一人称の表現
- 比較データ（ランキング・数値比較等）の捏造。裏付けのない数値は書かない
- 価格の断定表記。価格に言及する場合は、変動する可能性がある旨の注記を必ず添える
- 絵文字
- 数量・順序を表す漢数字（「第一に」「一つ目」等。算用数字で書く。「一度に」のような慣用表現は対象外）

## 文体サンプル（参照用）

以下は `D:\Claude_Code\AI_DropShipping_Store\research\week1-scripts.md` のSNS投稿キャプション案。
記事本文のトーン（簡潔で心地よく、断定を避ける）を揃えるための参照サンプルであり、そのまま転用はしない。

> 机の上が整うと、頭の中も整う。今の机と、これから直したい場所の記録です。少しずつ整えていきます。

> 片付けが続かないのは意思の問題ではなく、定位置が決まっていないから。まず「どこに戻すか」を決めると、机はそれだけで整い始めます。

> 実際に毎日使っているものだけ。{商品A/B/C}の3つは、値段以上に机の使い心地を変えてくれました。リンクはプロフィールにまとめています。

（3つ目の「実際に毎日使っている」は自社SNSアカウントの一人称投稿として書かれた文体サンプルであり、
本ブログ記事では禁止事項のとおり一人称の実体験表現としては使わない。文のリズムと簡潔さのみを参考にする。）
